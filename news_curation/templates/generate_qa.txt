You are given extracted facts from multiple news articles about the same event.
Each fact has been mentioned in at least 3 different articles.

TASK
Generate up to 12 QA pairs based on the provided facts and articles.

HARD RULES (must satisfy all; otherwise DO NOT output that QA)
1) Short-answer only:
   The answer must be a short span: who/what/when/where/how many/how much/outcome.
  e.g. name/date/number+unit/location/outcome/etc.
2) Anchor requirement:
   The questions must be precise and include the time stamp (ideally an absolute date with year)
3) Numbers:
   If the answer contains a number, it MUST include its unit in the answer exactly as written
4) No vague wording/references: One should be able to understand the questions without extra context. Avoid vague references like "the company", "the event", "the incident", "the organization", "his cousin", etc.
   Do not use these in the QA: "recently", "some", "many", "experts", "critics", "reportedly", "sources said"
   Do not use these in the Answer: "over ...", "approximately ...", "more than ..."
   Do not use these in the Question: "According to reports, ...", "What is ... of his cousin?", "What happened to the company"
5) Directly stated:
   Use only what is explicitly stated in the provided articles. No inference, no background.
6) 3-article support with SAME EXACT ANSWER:
   A QA is allowed only if the SAME EXACT information of the answer appears in at least 3 different articles
7) You may use the list of facts as the inspiration.
8) Spam Filter: If the article cluster is primarily SEO spam, affiliate content, or marketing disguised as news, return {"qas": []}.

SELECTION / DEDUPING
- If multiple QAs would have the same short_answer for the same underlying claim, output only one.

OUTPUT FORMAT (JSON only; no extra text)
{
  "qas": [
    {
      "question": "...",
      "answer": "...",
      "root_articles_ids": [
        article_id,
        article_id,
        article_id,
        ...,
      ]
    }
  ]
}

The "root_articles_ids" field lists the [Article N] IDs (1-indexed within this prompt) that contain the same exact answer.

IMPORTANT
- If fewer than 12 QAs satisfy all rules, output all that do.

Here are the extracted facts:

{facts}

Here are the articles:

{articles}
